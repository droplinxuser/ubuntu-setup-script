is refused **before the purge** because `php8.6-imagick` (Chevereto) and
`php8.6-redis` (XenForo) are unpublished; 8.6 also adds application-level
deprecations.

## 4. Anubis cost and the lean profile

Loopback, `wrk`, 100 connections, 8 s, gzip, TLS; the harness now sends
`User-Agent: setup-bench/1.0` (an empty UA is correctly challenged, which made
an earlier run measure challenge issuance).

| Tier | Anubis off | Anubis on | Delta |
|---|---:|---:|---:|
| WP guest home (cached) | 67 590 | 7 118 | -89 % |
| WP guest post (cached) | 60 439 | 6 937 | -89 % |
| XF guest home (cached) | 78 705 | 10 742 | -86 % |
| XF guest thread (cached) | 72 523 | 7 127 | -90 % |
| Chev explore (cached) | 68 345 | 6 979 | -90 % |
| Chev image page (cached) | 67 304 | 7 195 | -89 % |
| WP member home | 287 | 260 | -9 % |
| XF member home | 842 | 747 | -11 % |
| XF member thread | 512 | 408 | -20 % |
| Static asset (`/js/vendor/vendor-compiled.js`) | ~36 500 | 35 737 | ~0 % |

The static-only shadow keeps assets on the fast path; the proxy cost is the
large cached HTML body (Angie terminator + Go copy, ~10.6 cores at 7.1 k/s).
For a real site (hundreds of req/s) that is not a bottleneck; dynamic tiers
lose 9–20 %.

8 keeps the throughput with the same tail and bounds the runtime's appetite;
