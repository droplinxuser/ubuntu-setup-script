## 1. Code findings fixed

| Area | Defect | Fix |
|---|---|---|
| Anubis | `SOCKET_MODE=0666` in a `0755` `/run/anubis`: any local account could connect, pick `Host`, and forge `X-Real-IP` (backend trusts the unix peer) | `0660` in `0750`, `anubis:anubis`; `www-data` joined to the group; Angie reloaded before the socket is recreated; membership removed on disable, group on purge |
| Anubis | `anubis=no` stopped the filter before Angie loaded direct TLS → 502 window (permanent on a later failure) | stop deferred until a successful reload + 1 s drain; cancel on failure |
| Anubis | `listen 8443 ssl` matched as `443`; IPv6-only TLS listener dropped | exact port match; first TLS listener (v4 or v6) replaced, duplicates dropped |
| Anubis | version check assumed no `v` prefix | prefix normalised |
| Valkey | a full `noeviction` cache grew 20% on every run, up to the host cap | full non-evicting cache keeps `CURRENT`; `--valkey ram=` grows it |
| PHP upgrade | optional extension failure aborted the whole upgrade; failed purge bypassed rollback; failed autoremove probe purged every orphan; no post-Angie ini refresh | per-package optional installs, purge returns status → rollback, probe failure disables the delta purge, post-Angie `[PATH=]` refresh |
| CLI | `--domain` trailing `app=` leaked across a group after `db=`; empty `ver=` changed mode; `--upgrade-php --dry-run` ate the flag; invalid hostnames passed; `--elastic host=:port` passed | all validated before any change |
| OS | port 9000 not reserved in the widened ephemeral range; THP oneshot ran after DB units; `vm.max_map_count` not recorded | 9000 reserved; `Before=` ordering; original recorded |
| Angie | duplicate vhost roots doubled the OPcache table; Sury's `.deb` left a globally trusted key | `sort -u` roots; identical global key retired |
| Config repo | `/attachments/*.php` executable; subdirectory backup archives downloadable; subdirectory `wp-cron.php` reachable; headers dropped in cached PHP locations; internal scheme/port to proxies; 16 MiB proxy buffers; cache keys without public port/scheme; `gzip;q=0` got gzip; encoded dot separators; Cloudflare install-before-test; DHE without dhparam | see `server-configs-nginx` 1.6.35 changelog |
