# Audit host restore, setup.sh 1.21.8 (2026-11-15)

Host: `16c-32g-1T`, Ubuntu 26.04.1, 16 threads / 27 812 MiB / NVMe, bare
metal.  Baseline manifest: `cycle-1.21.8/baseline-manifest.txt` (527
packages, including the audit's `shellcheck` and `jq`), captured before the
first change.  Artifacts: `cycle-1.21.8/`.

## What the run installed

A fresh full stack: `--basic server=dedi --angie --php ver=8.5 --mariadb
user=demo pass=temp size=auto bind=127.0.0.1 --valkey --elastic
host=localhost ram=4g --others all`, three `--domain` vhosts, the three
applications, an 8.4 round-trip, and (for the compatibility scan only) a
co-installed PHP 8.6 CLI that was purged immediately afterwards.  The final
fresh install took 3:13 (7/7 steps OK, 0 ERR).  It added 94 packages
(527 -> 621); the delta is in `final-delta-after-run.md` and the pre-restore
host manifest is `final-after-run-manifest.txt`.

Also exercised on the host before the restore: `--optimize` (parity and
idempotency), `--diagnostics`, `--restart-all`, a repeated `--domain`,
`--basic --php ver=8.4` (refused with the upgrade hint),
`--upgrade-php=8.4`/`8.5`/`8.6`, `--purge valkey`/`others`/`basic` (with a
temporary `redis-server` to exercise the adopted-cache path), the functional
suite, the cookie-safety suite and the security probe.

Residual, non-actionable differences:

- `/etc/shadow-` is a backup copy rewritten by the package transactions; it
  is not configuration and is regenerated by the next shadow edit.
- `net.ipv4.neigh.default.unres_qlen_bytes` and the per-interface value
  differ from the manifest by one buffer size; the kernel recomputes them
  from `somaxconn` after a reboot.
- `net.ipv4.tcp_allowed_congestion_control` still lists `bbr` because the
  module remains loaded in the running kernel; the active algorithm is
  `cubic` and no `modules-load.d` entry keeps it.
- The load average decays from the audit run; no process from the run is
  left.

The work trees (`/root/work`, `/root/audit`), the `setup_*.log` files and
the `/tmp` artefacts were removed after this report, and the manifests plus
the logs in `cycle-1.21.8/` were copied to the repository.  The host keeps no
audit state.
